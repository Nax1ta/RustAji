# RustAji 1.0 · 首个公开版

RustAji 腐味是一款 Windows 本地网址收藏夹，用文件夹、标签、说明和封面整理课程、视频与文章。首次启动自带可编辑的图文教程。

## 下载

下载 `RustAji-1.0-windows-x64.exe`，直接运行。当前只支持 Windows x64；macOS 和 Linux 尚未提供版本。程序未进行代码签名，Windows 可能显示未知发布者提示。

## 主要功能

- 任意层级文件夹、拖放移动、复制与剪切粘贴。
- 标签、搜索、类型筛选、排序和全部资料列表。
- 网页封面自动查找与手动更换图片。
- 自定义主题、字体、文件夹配色与装饰。
- 本地资料位置迁移、完整 `.tlb` 备份与导入。

查看和整理已保存的资料可离线进行；打开外部链接和获取网页封面需要联网。个人资料默认在 `%LOCALAPPDATA%\腐味\`，不随程序更新覆盖。

源码见仓库，使用说明见 README 与 `docs/GETTING_STARTED.md`。
