# RustAji 1.0

RustAji（腐味）的首个公开版本。发布文件 `RustAji-1.0-windows-x64.exe` 仅支持 Windows x64。程序未签名，Windows 可能显示“未知发布者”。

首次启动会建立带配图的示例资料。网址资料可按文件夹整理，并附上标签、说明和封面；支持拖动、搜索、筛选和排序。

收藏内容保存在本机，默认目录为 `%LOCALAPPDATA%\腐味\`。已保存的资料和图片可离线查看；打开网址或自动获取封面需要网络连接。“备份”菜单支持导出、导入 `.tlb` 文件，导入会替换目标资料库。

目前没有 macOS 或 Linux 版本。源码、构建方法和许可说明见仓库 README。
