# RustAji 1.0

这是 RustAji（腐味）的第一个公开版本，只提供 Windows x64 程序。下载 `RustAji-1.0-windows-x64.exe` 后可直接运行。程序没有代码签名，Windows 可能提示“未知发布者”。

第一次打开会出现带配图的示例资料，按“从这里开始”里的顺序点下去即可熟悉界面。平时可以把网址放进文件夹，加标签、说明和封面；资料能拖动，也能搜索、筛选和排序。

收藏内容保存在本机。这个版本默认使用 `%LOCALAPPDATA%\腐味\`。已有资料和图片可离线查看；打开网址或自动寻找封面需要联网。换电脑可用“备份”菜单导出、导入 `.tlb` 文件。导入会替换目标电脑当前的资料，请先备份那边已有的内容。

macOS 和 Linux 版本尚未提供。源码、构建方法和许可说明见仓库 README。
