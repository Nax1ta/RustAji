# 十分钟上手 RustAji

第一次打开时，左边会出现几个示例文件夹。它们是普通资料，可以边看边改。

## 1. 认路

左边选文件夹，中间选资料，右边看封面、网址和说明。先打开“从这里开始”，点“01 认识腐味”。

## 2. 收藏一个网址

右键左侧的“从这里开始”，选“新建资料”。填名称和以 `https://` 开头的网址；说明里可以记下收藏原因、视频时间点或待做的事。保存后，双击资料会在默认浏览器打开链接。要把资料放在最外层，就右键左侧空白处。

## 3. 调整层级

右键文件夹可以建子文件夹。试着把一条资料拖到左侧的“整理与查找 → 试着移动到这里”。右键菜单里也有复制、剪切和粘贴。

## 4. 用标签找回资料

右键资料选“编辑标签”，填上你会用来查找的词。顶栏搜索框可以搜名称、说明或 `#标签`；中间列表的题头还能筛选类型和标签。

## 5. 配图和配色

新资料保存后，程序会尝试找网页封面。有些网站取不到，点右侧预览旁的“更换图片”即可换成本机图片。右键文件夹选“外观与图标颜色”，可以改文字、填充和图标颜色，也能调透明度与圆角。“配色灵感”里放了几组示例。

## 6. 备份与换设备

从“备份”菜单导出 `.tlb` 文件，在另一台 Windows 电脑上导入。导入会替换那台电脑当前的资料；如果那边已有收藏，先给它也导出一份备份。想把本机资料移到其他磁盘，用“设置 → 资料位置”。

资料库默认位于 `%LOCALAPPDATA%\RustAji\`。查看已有资料不用联网；打开网址和获取网页封面需要联网。
