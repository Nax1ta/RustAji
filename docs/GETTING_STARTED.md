# 十分钟上手 RustAji

第一次启动时，软件会创建一份可修改的示例资料库。图文教程就在软件里，不必先读完这篇文档。

## 1. 认路

左边是文件夹，中间是当前文件夹的内容，右边是所选内容的封面、网址和说明。打开“从这里开始”，点“01 认识腐味”。右侧的图和文字会解释这三个区域。

## 2. 收藏一个网址

右键左侧的“从这里开始”，选“新建资料”。填写资料名称和 `https://` 开头的网址。说明里写“为什么收藏”“下次要看哪一段”“我学到了什么”。保存后，双击资料会在默认浏览器打开链接。想把资料放在顶层，可以右键左侧空白处。

## 3. 调整层级

右键文件夹可建子文件夹。把一条资料拖到左侧目标文件夹即可移动，也可使用右键的复制、剪切、粘贴。示例文件夹“整理与查找 → 试着移动到这里”可用来练习。

## 4. 用标签找回资料

右键资料选“编辑标签”，加入如“绘画”“待看”“重点”的标签。在顶栏搜索框输入名称、说明或 `#标签`；中间列表的题头还可以筛选类型和标签。

## 5. 配图和配色

保存网址时，程序会尝试获取网页封面；获取失败或不合心意时，点右侧预览旁的“更换图片”，选一张本机图片。右键文件夹的“外观与图标颜色”可以调色、透明度和圆角。示例“配色灵感”保留了几组配色供参考。

## 6. 备份与换设备

选“备份 → 导出完整备份”，保存 `.tlb` 文件。另一台 Windows 电脑可用“备份 → 导入备份”读取。导入会替换目标电脑的当前资料，先把那边的内容也导出备份。想把本机资料放到其他磁盘，在“设置 → 资料位置”中迁移。

资料库默认位于 `%LOCALAPPDATA%\腐味\`。查看和整理已保存的记录无需联网；打开外部网址和获取封面需要联网。
