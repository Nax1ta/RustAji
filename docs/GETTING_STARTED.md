# RustAji 使用说明

安装时可分别选择程序文件和收藏资料的保存位置。首次启动会建立示例文件夹和资料。示例与普通资料相同，可编辑或删除。

## 1. 界面

左侧是文件夹，中间是资料列表，右侧显示当前资料的封面、网址和说明。内置教程位于“从这里开始 → 01 认识腐味”。

## 2. 收藏一个网址

右键左侧文件夹，选择“新建资料”，填写名称和以 `https://` 开头的网址。说明字段可记录收藏原因、视频时间点或待办内容。保存后双击资料，会在默认浏览器中打开链接。左侧空白处的右键菜单可在最外层新建资料。

## 3. 调整层级

右键文件夹可建立子文件夹。资料可拖到左侧的其他文件夹，右键菜单也提供复制、剪切和粘贴。

## 4. 用标签找回资料

右键资料选择“编辑标签”。顶栏搜索框支持名称、说明和 `#标签`；中间列表的题头可筛选类型和标签。

## 5. 配图和配色

新资料保存后，程序会尝试获取网页封面。部分网站的封面无法自动取得，可通过右侧预览旁的“更换图片”选择本机图片。文件夹右键菜单中的“外观与图标颜色”可调整文字、填充和图标颜色，以及透明度与圆角。内置“配色灵感”文件夹提供示例。

## 6. 备份与换设备

“备份”菜单可导出 `.tlb` 文件，再在另一台 Windows 电脑上导入。导入会替换目标资料库；现有资料应先单独备份。本机资料目录可在“设置 → 资料位置”中迁移。

未在安装时更改位置时，默认资料目录为 `%LOCALAPPDATA%\RustAji\`。已保存的资料可离线查看；打开网址和获取网页封面需要网络连接。卸载程序不会删除资料库。
