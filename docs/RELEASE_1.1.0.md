# RustAji 1.1.0

本版新增 Windows x64 安装包。安装流程分别提供程序安装目录和资料保存目录，两个目录都可选在 C 盘以外。安装包建立开始菜单入口及卸载项，采用浅灰绿色界面。卸载时保留资料库。

已使用旧版的电脑会沿用原资料位置；需要迁移时可使用软件内的“设置 → 资料位置”。新安装默认将资料保存在 `%LOCALAPPDATA%\RustAji\`，也可在安装时选择其他目录。资料、说明和图片可离线查看；打开网址或自动获取网页封面需要网络连接。

下载 `RustAji-1.1.0-setup-windows-x64.exe` 运行。安装包未签名，Windows 可能显示“未知发布者”。
