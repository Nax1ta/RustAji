# RustAji 1.0.1

这次更新改了默认资料路径，也调整了 README 和入门文字。软件功能与 1.0 相同，仍只提供 Windows x64 程序。

新版默认把资料放在 `%LOCALAPPDATA%\RustAji\`，位置设置保存在 `%APPDATA%\RustAji\`。第一次运行时，如果找到旧版 `%LOCALAPPDATA%\腐味\` 的资料，会复制记录、图片和设置到新目录；旧目录留在原处。以前由软件创建的“腐味资料”目录会复制到同一父目录下的 `RustAjiLibrary`。自己选择的其他目录不会自动改名。

下载 `RustAji-1.0.1-windows-x64.exe` 运行即可。程序未签名，Windows 可能提示“未知发布者”。打开网址和自动获取网页封面需要联网；已经保存的资料、说明和图片可以离线查看。导入 `.tlb` 备份会替换当前资料，操作前请先给现有资料做备份。
