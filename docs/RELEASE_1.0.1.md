# RustAji 1.0.1

1.0.1 将默认资料目录改为英文名称，并修订了项目说明与入门资料。功能与 1.0 相同；发布包仅支持 Windows x64。

默认资料目录为 `%LOCALAPPDATA%\RustAji\`，位置配置保存在 `%APPDATA%\RustAji\`。首次运行 1.0.1 时，旧版 `%LOCALAPPDATA%\腐味\` 中的记录、图片和设置会复制到新目录，原目录保留。旧版自动建立的“腐味资料”目录会复制到同一父目录下的 `RustAjiLibrary`；手动选择的其他目录不变。

下载文件为 `RustAji-1.0.1-windows-x64.exe`。程序未签名，Windows 可能显示“未知发布者”。已保存的资料、说明和图片可离线查看；打开网址及自动获取网页封面需要网络连接。导入 `.tlb` 备份会替换当前资料库。
